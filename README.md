# Корутины
домашка, здравствуйте
Корутины (от англ. coroutines, также сопрограммы) — это блоки кода, которые могут как выполняться полностью, так и временно приостанавливать свою работу, сохраняя при этом все локальные данные и контекст для последующего продолжения с того же места. Это позволяет организовать асинхронное выполнение задач, эффективно переключая управление между ними без блокировки основного потока.
Как это работает:
Когда корутина встречает операцию, которая может занять значительное время (например, чтение из сети или диска), она добровольно приостанавливает своё выполнение, уступая управление, но сохраняя всё своё состояние. В этот момент поток освобождается и может заняться другой корутиной. Когда первая корутина завершит свою операцию, она возобновляется и продолжает выполнение с того же места.
